# Setup

This package keeps the README design exactly in the requested style.

## Upload
Upload the whole package to your GitHub profile repository:

`ihyaabrar/ihyaabrar`

Keep these folders:
- `assets/`
- `scripts/`
- `.github/workflows/`
- `profile-3d-contrib/`

## First run
After the first push, open **Actions** and run these workflows once:

1. **Profile Cards**
2. **GitHub Profile 3D Contrib**
3. **Contribution Snake**

The included placeholder SVG files prevent broken-image boxes before those workflows finish.

## Permissions
If a workflow cannot push generated assets:

`Settings → Actions → General → Workflow permissions → Read and write permissions`

## Notes
The README itself is the requested classic layout. The only changes are behind the scenes:
- profile cards are generated locally inside GitHub Actions;
- placeholders are bundled from day one;
- 3D and snake sections keep the original paths and are replaced by their workflows.
